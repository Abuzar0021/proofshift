# ProofShift v0.3 — open agentic web adapter lab
Three independently keyed Node provider processes on distinct loopback origins; one fixed-policy verifier. They are synthetic services on one machine, not independent organizations. Each provider publishes a portable Neuro SAN manifest, resolved network and a read-only bridge action for historical test evidence. The front agent publishes a read-only deterministic snapshot verifier. The direct live gate retrieves nonce-bound evidence independently of model prose. A peer can describe or transport evidence, but only the deterministic gate decides the fixed policy. No payment, production data or release action exists.
Run Node 22+: npm test; npm run samples; npm start. Open http://127.0.0.1:8800. Historic mode runs from a static host; live lab uses only loopback fixture processes. Keep test keys separate from receipts; never use fixture keys as production trust roots. Generated historical receipts are not time-notarized. Model inference is optional, user chooses a provider. Do not enter secrets.
Built using Cognizant's Apache-2.0 reference runtime, copied unmodified from its checked-out repo. The test provider bridge exposes historical envelopes only, not real business commitments. Local runtime and deployment checks must pass before any conformance claim. Public hosting, actual independently hosted organizations, real LLM-mediated calls, and entrant video remain separate gates.
